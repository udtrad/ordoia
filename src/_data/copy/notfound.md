The 404 page. Prose only — see copy/home.md for the fragment format.

BRIEF.md §5 asks for "a 404 that is a page rather than a host default", and §9 calls a
published version returning 404 "the most serious operational failure this site can
have". So this page does one job beyond apologising: it names the addresses that are
guaranteed, and it says whose fault it is when one of them fails.

@@ heading
That address does not resolve

@@ body
Nothing is published here. If you followed a link from inside this site, that is a defect on our side rather than a mistake on yours.

If you typed an address off a printed scorecard, off a working paper, or out of somebody's standards document, it should have worked. A published rubric version keeps its address indefinitely — that is the whole point of printing one on an artifact — so `{domain}/oal/v{version}` failing would be a failure of this practice's own permanence guarantee, and we would want to know.
